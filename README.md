# Vance Medical — Website

Single-page marketing site for Vance Medical (vancemedical.co.uk). Sister company to SLA Pharma, specialising in medical foods (FSMP) for gastrointestinal health.

## Stack
- Next.js 14 (App Router) + TypeScript
- Tailwind CSS
- Deployed on Vercel

## Local dev
```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Assets
Place the logo at `public/logo.png` (transparent PNG, recommended 1024×320 or similar aspect).

## Palette
Primary teal `#008080`, `#78BFBF`, `#AEDBDB`, `#DEF4F4`, `#F4FFFF`.

## Deployment
Connected to Vercel project `slapharma/vance-medical-website`.
